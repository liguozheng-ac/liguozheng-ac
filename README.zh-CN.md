**AI Agent 产品设计与开发 · 语音交互 · 评估与质量工具**

我关注 AI Agent 如何从理解需求走向可验证的任务执行，通过 Codex 辅助开发，探索实时语音、后台任务协同、工具权限与执行结果验证。同时开展中日语言与语音质量工具实践。

### 我的质量评估方法

- 用确定性规则检查技术约束，用模型辅助分析依赖上下文的问题。
- 将实测证据、模型预测与人工批准分开处理。
- 保持实验可复现，保留失败案例，并明确说明不确定性。
